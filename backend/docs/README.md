# backend/docs — organización

Clasificado durante Fase 0 (Recovery), Recovery-10.

- **Raíz de esta carpeta**: documentación viva — guías reutilizables, todavía aplicables (`MANUAL_TEST_CHECKLIST.md`, `human_test_runner.md`).
- **`historical/`**: documentación histórica — reportes de fixes/versiones pasadas con narrativa y decisiones de diseño reales, conservados como memoria institucional aunque estén superados por la arquitectura vigente (vNext 1.2 y el Product Definition).
- **No versionado**: reportes generados automáticamente por scripts de simulación/auditoría (`P0_E2E_REPORT.md`, `P0_FIX_FINAL_REPORT.md`, `V3.0.3_UX_IMPROVEMENTS_REPORT.md`, `V3.0.4_AUDIT_REPORT.md`, `PRODUCTION_STATUS_V304.md`) — mismo género que `backend/reports/`, con tablas de métricas y sin narrativa de diseño; se excluyen del control de versiones por la misma razón que esa carpeta.
