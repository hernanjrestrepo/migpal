## Módulos Implementados

### 1. Profile Checklist (`profile_checklist.py`)

**Propósito:** RAG + checklist de datos requeridos para decisiones críticas.

**Categorías del checklist:**
| Categoría | Campos Requeridos | Prioridad |
|-----------|-------------------|-----------|
| Familia | has_family, family_count, children_ages | 1 |
| Edad | birth_date, age | 2 |
| Idioma | english_level | 3 |
| Presupuesto | savings | 4 |
| Estatus | visa_history, visa_denials, legal_issues | 5 |
| Objetivo USA | migration_reason, timeline | 6 |

**Funciones principales:**
```python
# Verificar completitud del perfil
result = check_profile_completeness(user_id, user_data)
# Returns: {complete, percentage, missing, can_recommend_visa, can_generate_plan}

# Obtener siguiente pregunta
next_question = checklist.get_next_question(user_id, lang)
# Returns: (field_name, question) or None
```

### 2. Test-Time Reasoning (`test_time_reasoning.py`)

**Propósito:** Generación multi-draft con selección del mejor.

**Enfoques de generación:**
| Enfoque | Descripción | Bonus Score |
|---------|-------------|-------------|
| Conservative | Requisitos estrictos, obstáculos | +0.10 |
| Optimistic | Fortalezas, oportunidades | +0.00 |
| Alternative | Rutas no convencionales | +0.05 |
| Edge Case | Casos límite, contingencias | +0.05 |

**Proceso:**
1. Generar 2-4 borradores con diferentes enfoques
2. Validar coherencia de cada borrador
3. Calcular score final (coherencia 60% + no-inventado 30% + bonus 10%)
4. Seleccionar el mejor

**Funciones principales:**
```python
# Análisis de visa
result = await reason_visa_analysis(user_data, context)

# Plan de migración
result = await reason_migration_plan(user_data, context)

# Detección de inconsistencias
result = await check_inconsistencies(user_data)
```

### 3. Coherence Validator (`coherence_validator.py`)

**Propósito:** Validar que las respuestas no inventen datos.

**Validaciones:**
- Detectar datos inventados (nombre, edad, profesión, salario, etc.)
- Detectar asunciones no verificadas ("basado en tu perfil" sin datos)
- Verificar consistencia lógica (edad vs educación, experiencia vs edad)
- Detectar contradicciones con datos confirmados

**Funciones principales:**
```python
# Validar respuesta
result = validate_response(response, user_data, lang)
# Returns: ValidationResult con issues, score, blocked, suggestions

# Verificar si es segura
is_safe, reason = is_response_safe(response, user_data, lang)

# Obtener respuesta segura o fallback
safe_response = get_safe_response(response, user_data, lang, fallback)
```

## Reglas Duras Implementadas

### 1. UNDERSTANDING Confirmado
- No se puede recomendar visa sin checklist mínimo completo
- Campos mínimos: age, english_level, profession, education_level, migration_reason, visa_history, legal_issues

### 2. No Recomendar Sin Contexto
- `can_recommend_visa()` verifica campos mínimos
- `can_generate_plan()` requiere checklist completo
- Si falta información, se pide al usuario

### 3. No Inventar Datos
- `CoherenceValidator` detecta datos no confirmados
- Patrones de detección para: nombre, edad, profesión, salario, ahorros, educación, historial de visa
- Respuestas con datos inventados son bloqueadas

### 4. No Aprendizaje Online
- Los módulos NO aprenden de usuarios reales
- Solo usan lógica y datos confirmados
- Feedback solo curado (no implementado en esta versión)

### Scoring de Drafts
```
final_score = (coherence_score * 0.6) + 
              (no_invented_penalty * 0.3) + 
              (approach_bonus) + 
              0.1  # base
```

### Severidad de Issues
- **CRITICAL**: Bloquea la respuesta (datos inventados, contradicciones)
- **WARNING**: Permite pero advierte (asunciones, inconsistencias lógicas)
- **INFO**: Solo informativo
