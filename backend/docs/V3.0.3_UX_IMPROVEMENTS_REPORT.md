## 1️⃣ Startup Self-Check

### Descripción
Validación automática al iniciar el bot que verifica que todas las constantes de estado usadas en `FORM_STATES` existan. Si falta alguna, el bot aborta con un error claro.

### Implementación
```python
# En telegram_bot.py - método start()
validator = get_startup_validator()
if not validator.run_startup_check(module_globals, FORM_STATES_CHECK):
    logger.error("❌ STARTUP ABORTED: State validation failed")
    raise RuntimeError("Bot startup aborted due to state validation failure")
```

### Log de Ejemplo
```
2026-01-07 07:54:05 - 🔍 Running startup self-check...
2026-01-07 07:54:05 - ✅ Startup check passed: 49 state constants, 7 phases validated
```

### Beneficio
Previene bugs como el P0 (NameError) detectándolos antes de que el bot inicie.

## 2️⃣ Global Exception Handler

### Descripción
Handler de errores global que captura cualquier excepción en handlers, loggea el stack trace completo con user_id y state, y envía un mensaje de fallback localizado al usuario.

### Implementación
```python
# Decorador para handlers
@global_error_handler
async def _handle_message(self, update, context):
    ...

# Error handler global registrado
self.application.add_error_handler(error_handler)
```

### Mensaje de Fallback
- **ES:** "⚠️ Ocurrió un error inesperado. Por favor intenta de nuevo o escribe /start para reiniciar."
- **EN:** "⚠️ An unexpected error occurred. Please try again or type /start to restart."

### Log de Error
```
🔴 ERROR | user=12345 | state=name | context=_handle_message | error=ValueError: Test error
```

### Beneficio
El bot nunca queda "trabado" en silencio. Siempre responde al usuario.

## 3️⃣ Timeout/Anti-Stall

### Descripción
Sistema que detecta usuarios estancados por:
- Timeout: Sin actividad por X minutos (configurable, default 10 min)
- Repetición: N mensajes idénticos consecutivos (default 3)

### Implementación
```python
class StallDetector:
    def record_activity(self, user_id, state, message)
    def is_stalled(self, user_id) -> (bool, reason)
    def get_stall_message(self, lang, last_prompt) -> (msg, buttons)
```

### Mensaje de Intervención
```
👋 ¡Hola! Noté que llevas un rato sin avanzar. ¿Necesitas ayuda con algo?

📝 *Última pregunta:*
[último prompt]

[▶️ Continuar donde estaba] [🔄 Reiniciar esta fase]
```

### Beneficio
Reduce abandonos al re-enganchar usuarios confundidos.

## 4️⃣ Confirmación de Nombre Simplificada

### Descripción
Mejoras en el flujo de confirmación de nombre:
- **1-Click:** Botones Sí/No en la misma línea
- **Auto-confirm:** Nombres bien formateados (ej: "María García") se confirman automáticamente
- **Dedupe:** Si el usuario ingresa el mismo nombre, se salta la confirmación

### Implementación
```python
class NameValidator:
    def is_valid_name(name) -> (bool, cleaned_name)
    def is_duplicate(new_name, existing_name) -> bool
    def should_skip_confirmation(name) -> bool
```

### Flujo Optimizado
```
Usuario: "María García López"
Bot: ✅ Nombre guardado: *María García López*
     ¿Cuál es tu fecha de nacimiento?
```

### Beneficio
Reduce fricción en el paso más común del onboarding.
