## Fixes Applied in V3.2.1

### Fix 1: Increased Token Limits
```python
MAX_NAME_LENGTH = 60  # Was 20
MAX_NAME_TOKENS = 5   # Was 2
MIN_TOKEN_LENGTH = 1  # Was 2
MAX_TOKEN_LENGTH = 20 # Was 15
```

### Fix 2: Word Boundary Pattern Matching
Changed from substring to word boundary matching to prevent false positives (e.g., 'vale' in 'Valentina').

### Fix 3: Added Missing Methods
Added `has_strong_name_signal()` and `extract_name_from_signal()` to V3.2.0 validator.

### Fix 4: Fixed Character Validation
Allowed apostrophes (O'Brien), hyphens (Jean-Pierre), and periods (J. Smith).

### Fix 5: Fixed English Extraction Patterns
Added accented characters (À-ÿ) to English patterns for names like "María José García López Hernández".
