# Arquitectura MigPAL (alto nivel)

## Objetivo
Construir MigPAL como una plataforma digital con IA para acompañar procesos de migración, con modelo de referidos multinivel y alta escalabilidad.

## Componentes (a definir en código)
- Frontend web (onboarding, seguimiento, referidos)
- Backend API (usuarios, procesos, pagos, referidos)
- Persistencia (DB)
- Integraciones (pagos, notificaciones, terceros)

## Principios
- Separación clara de responsabilidades
- Escalabilidad desde el MVP
- Automatización primero, humanos solo donde aporten valor
- Todo servicio documentado y verificable

Las decisiones deben alinearse con lo ya definido en los chats del proyecto MigPAL.
